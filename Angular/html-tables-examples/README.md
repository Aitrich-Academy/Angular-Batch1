# HTML Tables — 20‑minute teaching kit

Files in this folder:
- 01-basic-table.html — smallest useful example using `<table>`, `<tr>`, `<th>`, `<td>`.
- 02-semantics-thead-tbody-tfoot.html — shows `<thead>`, `<tbody>`, `<tfoot>` and a `<caption>`.
- 03-rowspan-colspan.html — demonstrates `rowspan` and `colspan`.
- 04-styled-with-css.html + table.css — modern styling that replaces old attributes.
- 05-accessible-table.html — uses `<caption>` and `scope` for better screen reader support.
- 06-responsive-table.html — horizontal scrolling pattern on small screens.
- 07-deprecated-attributes.html — old attributes for contrast (do **not** use in production).

Open each file in your browser to demo during the talk.
